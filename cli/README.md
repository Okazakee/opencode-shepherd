# opencode-shepherd CLI

The standalone, dependency-free CLI behind
[opencode-shepherd](https://github.com/okazakee/opencode-shepherd): watch
opencode sessions and respond when they need you.

This directory is the CLI's own packaging (`pyproject.toml`, `src/`, `tests/`).
Install and usage instructions live in the repository root
[README](../README.md); the Hermes plugin at the repository root is
skills-only and never installs this package by itself.
